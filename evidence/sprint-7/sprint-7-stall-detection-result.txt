# S7_outer_pulse_detects_stall_test

Acceptance criterion verbatim:
"tests/outer-pulse/stall-detection.sh: backdate last-beat by 25 minutes, invoke goal-supervisor heartbeat, confirm it produces a recovery note and (if webhook configured) attempts a Discord POST."

Detailed acceptance criterion verbatim:
"tests/outer-pulse/stall-detection.sh does the following in a mktemp scratchroot:
1. Creates a fake active.jsonl with one session whose workspace is also a mktemp dir.
2. Creates the workspace's .claude/goal-state/last-beat with a timestamp 25 minutes in the past.
3. Creates a passing goal-state.json (status not "complete").
4. Sets SUPERVISOR_ACTIVE_LEDGER, SUPERVISOR_STALL_THRESHOLD=1200, SUPERVISOR_RECOVERY_LOG, SUPERVISOR_DISCORD_WEBHOOK (optional -- if set, the test installs a curl function override that always succeeds and asserts it was called).
5. Invokes scripts/supervisor-runner.sh.
6. Asserts: exit 0; the recovery log has exactly one JSON line for that session with last_beat_age_seconds >= 1500 (25 min); if webhook was set, the curl override fired at least once.
7. Cleans up the mktemp dirs.
- A second sub-test asserts that a session with a FRESH last-beat (less than 60s ago) does NOT produce a recovery note."
