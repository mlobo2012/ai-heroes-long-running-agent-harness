T3 — Five-point rationale for keeping the flag (lines 16-42).
  1. The harness IS the boundary — autonomous loops cannot have per-tool
     approval gates by definition.
  2. Operator controls supersede Codex's own — AGENT_STOP, STEER.md,
     verify-gate, 8-block cap, all run from Claude Code's hook layer
     (parent of the Codex subagent).
  3. -C "$WORKDIR" pins Codex's working directory to the goal workspace.
  4. CODEX_MODEL is pinned with a hard refusal list (exits 3 on
     gpt-5.5-codex / gpt-5.4).
  5. --skip-git-repo-check is benign.

T4 — Threat model explicitly names what the harness does NOT defend
     against (lines 43-65).
  - Misaligned Codex prompt: brief is the boundary, not the sandbox.
  - Malicious operator: anyone with shell access can edit hooks / fake
    goals / write STEER.md. Productivity surface, not auth boundary.
  - Bash sed/jq on test-results.json: verify-gate only hooks Write|Edit;
    this is the documented soft boundary upstream. evaluator-strict.md
    is the partial close (drop Bash from the *evaluator*); the
    generator's Bash access is the productivity surface kept.
  - Egress to the public internet: Codex with sandbox bypass can curl
    anywhere; no hard block; recommendation is offline host or drop the
    bypass flag for network-sensitive goals.

T5 — Hardening paths an operator can opt into (lines 67-81).
  - Drop the bypass flag.
  - Use firejail / macOS Seatbelt / Docker as the launcher's outermost
    process.
  - Use evaluator-strict.md.
  - Run on a dedicated machine.

T6 — TL;DR section (lines 83-90) summarizes the trade.
  States the actual trade: sandbox isolation at Codex layer ↔ autonomous
  runtime; real operator controls at the parent layer (AGENT_STOP,
  STEER.md, verify-gate, 8-block cap, pinned model). Points the reader
  at bin/codex-spawn.sh and hooks/heartbeat-stop.sh to verify the
  controls are real.

T7 — Closes the matrix gap.
  Matches the docs/parity-gap-analysis.md item for "sandbox bypass
  documented honestly." Closes the meta-gap that an operator new to the
  harness could not previously understand why the flag is there or how
  to tighten the threat model.
