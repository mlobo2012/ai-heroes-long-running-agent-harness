S18_blocker_ledger

Acceptance criterion verbatim:
- .claude/goal-state/blockers.jsonl is the canonical ledger location. The file is append-only; status updates land as new lines with the same id (latest-wins on read).
- Schema (from design note): id, title, severity (critical|high|medium|low|nit), status (open|triaged|resolved|wontfix), discovered_at (ISO8601), discovered_by, evidence_paths (array), reproduction_notes, affected_area, resolution_notes.
- scripts/blocker-record.sh CLI: blocker-record.sh --title "..." --severity <s> [--id <id>] [--evidence path1,path2,...] [--reproduction "..."] [--area "..."] [--by "..."]. Generates id as B-<slug-from-title> if not provided. Sets status: open, discovered_at: $(date -u -Iseconds). Validates severity enum. Appends JSON line.
- scripts/blocker-update.sh CLI: blocker-update.sh --id <id> --status <s> [--evidence path1,path2,...] [--resolution "..."]. Rejects unknown id. Validates status enum. Appends JSON line.
- Both scripts are bash (use python3 for JSON construction). Both fail loud on invalid input.

File-and-line citations:
